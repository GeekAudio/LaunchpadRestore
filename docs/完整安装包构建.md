# 完整原生启动台安装包

软件包版本 `2427.6.10` 改进安装与卸载流程。包内 Dock 的代码、二进制补丁、签名参数以及
`LPRNativeExperimentVersion=2427.6.9` 保持第九版实现，继续使用已验证的 Dock 客户端软件位图后端。

## 支持范围

目前仅支持 Intel / `x86_64`、macOS `26.7.1`、系统构建号 `25G241`。
安装器还会检查系统卷是否具备写入和创建启动快照的条件。其他系统版本和 Apple Silicon
不在此包的支持范围内。

系统需已关闭 Authenticated Root，并具备运行重新签名系统程序的代码签名策略。
本机验证环境包含放宽的 AMFI 配置；没有在默认 AMFI 策略下验证。完整包不会更改
SIP、AMFI、EFI 或驱动，因此“无需 OCLP”不表示普通 Mac 默认安全配置下可直接替换系统 Dock。

安装包携带完整的候选 `Dock.app`、偏好设置助手、bundle 库存/备份验证助手和安装脚本。目标电脑不需要事先安装
OCLP、旧版启动台或本项目，也不需要事先存在 `Dock.app.orig`。

首次安装会保存目标电脑自己的原版 Dock，卸载依赖这份本机备份。安装包不会把构建电脑的
`Dock.app.orig` 当作目标电脑的原版备份分发。

## 构建

在支持的构建系统上运行：

```sh
./scripts/build-native-entry-pkg.sh --source /absolute/path/to/Dock.app
```

`--source` 指向未经修改的 Apple Dock `2427.6` 完整 bundle。脚本核对版本和可执行文件
SHA-256；当前接受的原始通用可执行文件为：

```text
278ed95b86bdef7e122820a0251c5a607fec377c217fae34a651397e8082e193
```

省略 `--source` 时，脚本使用构建电脑的
`/Library/Application Support/LaunchpadRestore/Dock.app.orig`。
这是构建源的默认位置，不是目标电脑安装的前置条件。

脚本仅构建文件，不安装、不修改运行中的 Dock、不重启。它从原版提取 `x86_64` 切片，
应用第九版原生入口补丁，保留完整 bundle 资源，再签名并打包。

## 输出与安装

输出位于项目 `pkg/` 目录：

| 文件 | 用途 |
| --- | --- |
| `LaunchpadRestore-Native2427-Full-2427.6.10.zip` | 完整分发，含两个 pkg、中文说明和 SHA-256 |
| `LaunchpadRestore-Native2427-Install-2427.6.10.pkg` | 完整安装包，启用原生启动台 |
| `LaunchpadRestore-Native2427-Install.pkg` | 同一安装包的固定文件名 |
| `LaunchpadRestore-Native2427-Uninstall-2427.6.10.pkg` | 卸载启动台并还原这台电脑自己的 Dock |
| `LaunchpadRestore-Native2427-Uninstall.pkg` | 同一卸载包的固定文件名 |

现有第九版、`Experiment` 和 `Rollback` 历史包保留，不由此构建覆盖。
需要安装启动台时选择 **Install**。截图中“还原本机原版 Dock”的包属于卸载用途；
没有有效本机备份时不能用它完成安装或通用还原。

两个新包都在安装器中展示说明。Install 首次安装自动备份本机原版；Uninstall 验证并使用
本机备份还原，并恢复已保存的渲染偏好。安装或还原准备好下次启动快照后，由用户选择何时重启。

## 包内清单

安装脚本旁的 `package-manifest.plist` 记录包版本、Dock 版本、支持的系统和架构、
原始源可执行文件哈希以及实际候选可执行文件哈希。安装和卸载脚本读取这份清单校验当前目标，
不依赖构建电脑上的路径。完整候选 `Dock.app` 放在安装包脚本归档内。
`bundle-inventory.plist` 另外记录候选 bundle 中每个普通文件的哈希、符号链接目标和目录，
用于检查完整资源库存。安装和卸载包都携带签名后的 `dock-bundle-state` 验证助手。

此改动解决分发完整性和首次安装/还原角色混淆，不代表其他 macOS 构建已经兼容。
第九版在当前用户的分辨率切换场景已获得成功反馈；重启后首次打开时偶见两个空白图标的
问题仍需单独处理。

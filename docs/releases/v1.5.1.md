## 这次更新

- **放开系统限制**：不再按 build 白名单拒绝安装，改为 **macOS 26.0 及以上、系统 Dock 仍为 `2427.6`** 即可。清单新增 `MinimumProductVersion` 与 `FallbackVariant`，按 build 精确匹配失败时自动回退。
- **新增 26.7.3（25G342）**：它的 Dock 与 26.7.2 逐字节相同（可执行文件 `0e13feca…`、Info.plist `13ee6ebf…`、x86_64 瘦切片 `d38193aa…` 全部一致），直接复用 25G332 的候选 Dock，不再单独构建。
- **未收录的 build 走回退变体**：用 25G332 的候选安装，但安装前会用 Apple 签名（`anchor apple`）确认本机 Dock 是原版，否则拒绝建立还原点。
- **备份仍按本机 build 存放**：`Originals/<当前 build>/`，卸载只还原本机 build 的备份，不会跨 build 套用。
- 修复 26.7.3 上安装直接失败的问题（`PKInstallErrorDomain Code=112`、日志「安装包不支持当前系统」）。

## 怎么安装

下载 **Full ZIP**，打开 **Install** 安装；**Uninstall** 用于卸载还原。完成后重启生效。系统更新或 OCLP 还原补丁后，需重新安装。

## 验证与已知问题

- 本机 26.7.3（25G342）选包结果为精确命中 `25G342` 变体；删掉该条目模拟未收录 build 时，正确回退到 `25G332` 并切换到签名校验分支。
- 26.7.2 候选 Dock 重建后 SHA-256 仍为 `9a9d4c08…`，与 v1.5 发布资产逐字节一致，构建可复现。
- 26.7.3 上启动台行为仍待实测。若后续系统把 Dock 换成新版本（不再是 `2427.6`），本包会拒绝安装而不会降级系统 Dock，需要重新构建候选。
- 首次打开偶发空白图标的问题尚未修复，反复开关后可恢复。
- 仅支持 Intel / `x86_64`；系统需允许修改 Dock，普通 Mac 默认安全设置下不能直接安装，异机首次安装尚未实测。

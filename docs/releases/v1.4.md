# v1.4 — 完整原生启动台（2427.6.10）

本版提供完整原生启动台分发包。目标电脑不需要预先存在旧启动台、OCLP 或
`Dock.app.orig`；安装时会备份目标电脑自己的 Dock，再安装包内完整 Dock。

## 下载与用途

- **Full ZIP**：包含 Install、Uninstall、中文使用说明及包文件的校验值。
- **Install.pkg**：安装原生启动台。
- **Uninstall.pkg**：卸载并恢复这台电脑首次安装时保存的 Dock 和渲染设置。
- **SHA256SUMS.txt**：三个下载文件的 SHA-256 校验值。

请按文件名选择用途。“还原本机原版 Dock”的包用于卸载；它需要有效的本机备份。

## 支持范围

- Intel / `x86_64`。
- macOS **26.7.1（25G241）**。
- 系统须已关闭 Authenticated Root，并具备运行重新签名系统程序的代码签名策略。

软件包不会调整 SIP、AMFI、EFI 或显卡驱动。普通 Mac 的默认安全配置不能直接替换
系统 Dock。其他系统 build 和 Apple Silicon 不在本版支持范围内。

## 本次改动

- 内置完整 Dock、图像资源、插件及 XPC 辅助程序，共 468 个文件。
- 首次安装自动暂存、校验并保存目标电脑自己的原始 Dock。
- 备份清单核对系统 build、架构、硬件、APFS 卷组和全部文件库存；不分发开发机的原始备份。
- 改进卸载校验、安装互斥和失败恢复，移除通过 SDK 名称推断系统兼容性的判断。
- 保留第九版的原生动画和客户端软件位图后端，避免此前本机的分辨率切换崩溃。
- 提供只读图标诊断工具；独立 Lunchpad 方案源码保留在仓库中，不作为本次发布附件。

软件包版本为 **2427.6.10**。包内 Dock 的 `LPRNativeExperimentVersion` 仍为
**2427.6.9**，主程序与当前已验证的第九版逐字节相同。

## 验证与已知问题

- 本机用户安装第九版并重启后，确认本次分辨率切换正常。
- 已核对完整包资源库存、候选及工具代码签名、安装器脚本与重启标记。
- **尚未在另一台未安装 OCLP 的电脑上实际安装验证。**
- **重启后第一次打开时，偶有两个图标短暂空白，反复开关后恢复；此问题尚未确认修复。**
- 软件位图绘制可能增加 CPU 工作量。

安装或卸载会准备下次启动快照，完成后由用户选择何时重启。
请保留 `/Library/Application Support/LaunchpadRestore/Dock.app.orig` 及同目录的备份清单。
安装日志位于 `/var/log/launchpadrestore.log`。
